## 方式三：GitHub Desktop（⚠️ 有局限）

**它不能像网页版那样点开文件看源码。**

GitHub Desktop 点 `.py` 文件打开的是 **diff 视图** —— 显示"这个文件相对上次提交改了什么"。
你的文件都已提交且无改动，**diff 是空的，什么都看不到**。

它能做的：
- 看文件树（左下角，知道有哪些文件）
- **Changes** 标签：看哪些文件改了、diff 对比
- **History** 标签：看提交历史
- **Show in Explorer**：用系统默认程序打开（已把 `.py` 关联到 VS Code）

所以：看**目录结构和提交历史**用 GitHub Desktop，看**代码内容**用 VS Code 或网页版。
