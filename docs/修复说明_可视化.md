## 一、致命错误：未定义的名字（6 处）

### 问题 1｜`Bar` 未定义

```python
Compare_Quarterlys_market_value_Stock_name_bar = Bar()
```

全文没有 `from pyecharts.charts import Bar`。

**后果**：`NameError: name 'Bar' is not defined`。

**修复**：`fundlab/visualize.py` 顶部 `from pyecharts.charts import Bar`。

---

### 问题 2｜`opts` 未定义

```python
...set_global_opts(title_opts=opts.TitleOpts(title="比较季度之间各个基金持仓股票持股总市值"))
```

**后果**：`NameError: name 'opts' is not defined`。

**修复**：`from pyecharts import options as opts`。

---

### 问题 3｜`pd` 未定义

三处 `pd.read_csv(...)` 全部没有导入 pandas。

**后果**：`NameError: name 'pd' is not defined`。

**修复**：`import pandas as pd`。

---

### 问题 4｜`web` 在函数作用域内不可见

原始代码把导入和函数体拆成了**两个独立的段落**：

```
段落4：  import webbrowser as web
段落5：  def Data_visual(...):
             ...
             web.open_new_tab(...)
```

即使这两段在同一文件里，段落 5 的函数体也**看不到**段落 4 的模块级导入 ——
除非段落 5 是段落 4 的嵌套（显然不是）。

**后果**：`NameError: name 'web' is not defined`。

**修复**：在 `fundlab/visualize.py` 顶部统一 `import webbrowser`。

---

### 问题 5｜`Position_Area` 未定义

```python
Compare_Quarterlys_market_value_Stock_name = pd.read_csv(
    '基金数据分析/处理数据/' + '连续二季度各个基金持仓股票持股总市值' + Position_Area + '-' + ...)
```

`Position_Area` 既没定义，也没在函数参数列表里（参数只有 `Year2, Quarterly1, Quarterly2`）。

**后果**：`NameError: name 'Position_Area' is not defined`。

**修复**：改为 `config.position_area`，由命令行 `--position-area` 传入。
这与上一个作业（基金持仓/市值融合）里 `Config.position_area` 是同一个概念，
两个模块现在共用一套参数。

---

### 问题 6｜`Year2` 是形参但从未使用

```python
def Data_visual(Year2, Quarterly1, Quarterly2):
```

`Year2` 在函数体里一次都没出现。

**后果**：不影响运行，但属于误导性接口 —— 调用者会以为传了年份有效果。

**修复**：年份已经由 `Config.current_year` / `previous_year` 承载，

## 二、会导致运行失败的问题（2 处）

### 问题 7｜输出目录不存在

```python
...render('基金数据分析/可视化结果/' + Quarterly1 + '与' + Quarterly2 + '...统计.html')
```

`基金数据分析/可视化结果/` 这个目录原始代码从不创建。

**后果**：`FileNotFoundError` —— 图表渲染直接失败。

**修复**：`out_dir.mkdir(parents=True, exist_ok=True)`。

---

### 问题 8｜收益率图的 `head(10)` 没生效

```python
Compare_Quarterlys_Rate_return = pd.read_csv('...连续二季度基金收益率前200....csv')
Compare_Quarterlys_Rate_return.head(10)      # ← 返回值没赋值，等于什么都没做
Compare_Quarterlys_Rate_return_bar = Bar()
```

`head(10)` 返回的是**新对象**，不写回原变量，这行是纯粹的空操作。

**后果**：文件名写的是"前200"，标题说"比较季度之间收益率"，
但图上实际画的是**全部 200 行** —— 一根柱子上 200 个类别，完全没法看。

**修复**：`rate = rate.head(top_n)`，并且标题里体现实际取了几名
（`比较季度之间收益率（前5名）`），文件名和标题保持一致。

## 三、跨平台与可维护性问题（3 处）

### 问题 9｜`web.open_new_tab` 用 Windows 反斜杠拼路径

```python
web.open_new_tab('基金数据分析\可视化结果\\' + Quarterly1 + '与' + Quarterly2 + '...统计.html')
```

反斜杠是 Windows 专有的路径分隔符。

**后果**：Windows 上能跑，**Linux / macOS 上完全失效**（GitHub Actions 跑不了），
而且路径一旦含空格就断。

**修复**：用 `pathlib` 统一处理，并转成标准 URI：

```python
webbrowser.open_new_tab(out_path.resolve().as_uri())
```

`as_uri()` 产出 `file:///D:/...` 这种标准形式，跨平台都能用。

---

### 问题 10｜浏览器自动打开在服务器上会失败

原始代码每画一张图就 `web.open_new_tab(...)`。

**后果**：在服务器 / Docker / GitHub Actions 里没有浏览器，这一步会抛异常或刷一堆错误，
而且**没法关闭**。

**修复**：抽成 `open_browser` 参数，CLI 上用 `--no-browser` 控制。
默认 `False`（CI 安全），本地用 `--visualize` 时自动打开。

---

### 问题 11｜`import os` 没用到

```python
def Data_visual(...):
    import os
```

整个函数没用到 `os`。

**修复**：删掉。

---

### 问题 12｜输出文件名和数据源对不上

原始代码第二张图：

```python
...render('...' + Quarterly1 + '与' + Quarterly2 + '重仓前10股票基金持有家数统计.html')
```

但它的数据源是 `连续二季度股票持有的基金持有家数`，而且**没有做 top10 截取**，
画的是全部行。文件名说"前10"，实际是全部。

**修复**：文件名和标题统一为「重仓股票持有基金数量」，
并通过 `--top-n` 真正控制截取行数。
