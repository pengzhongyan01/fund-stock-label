# 交付指南（提交作业 + 截图）

## 一、老师要的截图是什么？

**是"证据"，不是"作业本身"。** 作业实体是下面两样东西：

| 交付物 | 说明 |
| --- | --- |
| GitHub 仓库 | 代码本体。`fundlab/` 包 + 测试 + CI 配置 |
| Word 文档 | `代码阅读及调试-本次代码.docx`，含修复说明与修复后的完整代码 |

截图的作用是**证明代码真的跑起来了**。代码阅读与调试这门课的验收标准就是
"你读懂了这段代码、改对了、而且改完能跑"，截图就是把"能跑"这一条落实。

通常需要 **1～3 张**，按重要性排序：

| 优先级 | 截图 | 从哪儿截 | 截什么 |
| --- | --- | --- | --- |
| ⭐ 必交 | **GitHub Actions 全绿** | 仓库 → Actions 标签页 | 整个 workflow 列表，所有 job 都是 ✅ |
| ⭐ 必交 | **Actions 里 pytest 的输出** | 点进 test job → "运行测试" step | 末尾 `25 passed` 那一行 |
| 🟡 加分 | **本地运行成功的终端** | 本地终端 | `bash scripts/verify_local.sh` 的完整输出 |
| 🟡 加分 | **仓库主页** | 仓库首页 | README 渲染效果 + 文件列表 |

> 如果老师只说"发个截图"，交第 1 张（Actions 全绿）通常就够了。
> 但**保险起见交 1+2 两张**，因为只截 Actions 列表页有时看不出具体跑了什么。

## 二、推送到 GitHub（还没推的话）

### 1. 在 GitHub 网页上建仓库

- 打开 <https://github.com/new>
- Repository name：例如 `fund-stock-label`
- ⚠️ **不要勾选** "Add a README file"（本地已有 README，推送会冲突）
- 勾选 `.gitignore` → 选 `Python`
- 点 **Create repository**

### 2. 连接并推送（在本机项目目录执行）

```bash
cd D:/.workbuddy/statistic/2026-11-13-08-29-26

git remote add origin https://github.com/<你的用户名>/fund-stock-label.git
git branch -M main
git push -u origin main
```

推送时 GitHub 会要求登录，用**Personal Access Token** 代替密码：
GitHub → Settings → Developer settings → Personal access tokens → Generate new token
（勾选 `repo` 权限）。

### 3. 等 Actions 跑完

推送后：

1. 仓库页面会显示一个黄色的 **Actions** 在运行
2. 等 1～3 分钟，变成**绿色对勾** ✅ 就成功了
3. 点 **Actions** 标签页 → 选最新一次运行 → 就是你要截图的地方

### ⚠️ 如果 Actions 是红的

多半是这三种原因，对照排查：

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| `pip install` 报 `requires-python` | Python 版本太低 | 本项目已固定 3.11/3.12/3.13（pandas/akshare 已不支持 3.10） |
| `ModuleNotFoundError: fundlab` | 目录结构不对 | 确认 `fundlab/` 与 `tests/` 在仓库根目录 |
| `FileNotFoundError` 指向数据文件 | CI 里跑的是需要真实数据的步骤 | CI 只跑离线测试和样例数据冒烟测试，不会碰真实数据 |

## 三、截图怎么截才清楚

### Actions 全绿截图

1. 浏览器 **F11 全屏**（或至少把浏览器窗口放大），去掉书签栏
2. 进 Actions 页面，**滚到能看清 job 名称和状态**的位置
3. 截全屏（Windows: `Win + Shift + S`）
4. 要点：让 **"CI" 那一行，以及所有 ✅ 都在画面里**

### pytest 输出截图

1. 点进 `test` job（矩阵任务会展开成 3 个，选任意一个展开）
2. 左侧步骤列表点 **"运行测试"**
3. 页面会自动滚到该 step 的输出，**滚到最底部**（显示 `25 passed`）
4. 截图

### 本地终端截图

```bash
cd D:/.workbuddy/statistic/2026-11-13-08-29-26
bash scripts/verify_local.sh
```

（Windows Git Bash 里如果 `python3` 不存在，用 `PYTHON=python bash scripts/verify_local.sh`）

跑完整个终端窗口截下来，里面会依次显示：Python 版本 → 依赖安装 → 编译检查 →
`25 passed` → CLI 帮助 → "全部通过"。
